# Reference designs

Studies built in the studio and kept as files rather than as presets, so they
can be opened, changed and saved again without becoming part of the app.

Open one with **More → Import design**.

| file | what it is |
|---|---|
| `valmont-cushion-roman.json` | A cushion Roman study built from a photograph: champagne chapter ring, clous de Paris centre, radial black Romans with IIII at four, blued Breguet hands, printed name on a reserved cartouche. |
